scheme experiment interface does not freeze or establish general-construction refinement. S03 now

## Construction theorem ladder

- `Params.Valid` and per-set witnesses; derived-width and size theorems. (S03 implemented.)
- ADRS canonicality, field noninterference, rejecting decode/encode, and checked compression.
  (S03 implemented at the wire boundary; construction invariants remain later work.)
- `base2b_length`, digit bounds, MSB-first characterization, and checked fixed-width codecs.
  (S03 implemented.)
- Primitive interface coherence, especially `yToBytes`; concrete SHA2/SHAKE equivalence lemmas.
- `chain_compose`; WOTS digit/checksum incomparability; `pkFromSig_sign`.
- Merkle `climb_authPath`; XMSS and FORS recovery correctness with valid indices.
- General `d`-layer `htPkFromSig_htSign`, with index evolution invariants.
- Internal sign/verify correctness; codec round trip and reject laws.
- Pure/pre-hash API correctness for all 12 sets; executable vector results.

## Security/oracle surface (S02)

Define a single experiment configuration containing valid parameters, primitive families, public-seed
generation, interface mode, and oracle signature. The EUF-CMA key generated by the experiment owns
`PK.seed`; reductions receive it through the transcript, never as an unrelated universally supplied
constant. Define named query variants for signing, `PRF`, `PRF_msg`, `F`, `H`, `T_l`, and `H_msg`,
and use VCVio query instrumentation to obtain histories and costs.

Each bound is a predicate on an adversary/execution, such as `SigningBound adv qS` and
`HashQueryBound adv qH`, proved by enforcement or counting. Each quantitative component is a
standalone source-shaped game whose `pick` phase queries challenger-owned target oracles under
proposed D-009. The
formula-derived positive value is a cap on the actual target log, with distinctness and, for `-C`,
same-execution collection disjointness checked by the event. A program may make zero target calls;
then any selected-target event is false. These component targets are deliberately not manufactured
from the outer EUF transcript, and no caller-provided probability or target sampler is a
load-bearing interface. This candidate does not supersede the earlier outer-transcript contract
unless a named owner accepts D-009.

Define actual predicates for:

- EUF-CMA freshness and successful verification, including message/context/pre-hash mode;
- tweak-distinct SM-TCR/SM-DSPR/related notions required by the selected proof;
- ITSR using the actual `Hmsg` digest-to-`(idx_tree, FORS indices)` mapping;
- WOTS/FORS/XMSS transcript bad events and extraction targets;
- classical oracle access and QROM access as different types/models.

The S02 review must exhibit the proposed repaired (HK22/EasyCrypt) master theorem, all quantifier
order, positive cardinality conditions, exact coefficients, and the reduction dependency graph. It
must explain which historical CCS statement components remain valid comparison points without
reusing its invalidated WOTS reasoning. It must delete the invented
interleaving-loss placeholder or reclassify it as an explicitly unproved conjectural bound; it may
not proceed with a theorem that becomes trivial at zero targets or arbitrary samplers.

## Composition and asymptotics

Component reductions target the frozen notions. Top composition states finite concrete bounds with
checked query/time transformations. A separate asymptotic layer indexes parameter families by a
security parameter and proves negligibility/polynomial-query consequences. Concrete all-12-set
evaluations are finite security accounting, not asymptotic theorems. QROM results are stated only
when the semantics supports quantum oracle access; a classical `OracleComp` theorem is labeled
classical even if its assumptions are inspired by post-quantum literature.

## Refinement boundary

Executable Lean -> encoded bytes -> selected deployment ABI/implementation is a separate theorem
ladder. The target repository/commit, compiler/extractor if any, ABI, word/endian semantics, and
environment assumptions enter the TCB matrix. Until selected, the refinement theorem is blocked,
not postulated.
