# R0b: readable equations and ordinary-test enforcement

The five test modules expose forty fully quantified equations covering the eleven original
semantic groups. Their explicit right-hand sides retain the actual signing/verification order,
raw optional replies and exact pair freshness, all five source coordinates, the shared cache,
separate structural caps, actual joint probability-one budgets, lifetime, full deterministic and
hedged expressions, n32 weak-seed factor, profile selection, FIPS rejection and secret-first FORS.
The R0a fourteen-file baseline and all original production definitions remain unchanged.

The ordinary enforcement command is:

```sh
lake test
```

Its existing compiler, Game, WireBridge and FORS executables and independent eighteen-row
exact CSV check run once in their existing positions. Any nonzero exit returns immediately.
After that chain succeeds, a single Python tail gate validates immutable bindings and freshly
elaborates the four readable-equation leaves, checks their standard axiom sets, and invokes the
original R0a verifier once. It never recursively calls `lake test` and does not rerun the existing
executables or table generator. Additive independent test registrations are allowed; the whole
Lake file is not hash-frozen. The selected five executable/table targets retain their exact
module roots and source directories. A separate driver-scaffold digest erases only standalone
nonprotected exe-list entries; loop/error propagation, table-generator/checker and tail code
remain fixed. It freezes these selected bindings and control flow, not every future unprotected
executable.

The tail gate can be inspected separately:

```sh
python3 scripts/check-slh-dsa-r0b.py --report-dir /tmp/slh-dsa-r0b-check
```

That standalone command checks **bindings and fresh kernel contracts**. It does not claim that
the preceding runtime chain executed. Use a fresh external report directory. Source and all
locked dependency snapshots bracket every acceptance input, build and evaluator query.

`bindings.json` records the reviewed equation sources, the original runtime tests/support,
exact rational evaluator/generator/checker, original eighteen-row CSV, and the source of the
registered finite-index compiler rule. The original 127, low-q569 and verifier569–3824 statements
are five of R0a's literal contracts; their framing/parsing, acceptance and lifetime premises
remain intact. The new concrete equations also bind the actual128s dimensions, thirty-byte
answer carrier and conservative3929 cap. Hashes do not replace kernel proofs or actual runtime
assertions. Changed expected data is not a passing recovery argument; any update requires
separate review.

R0a's strict semantic fingerprints reject even benign changes to protected definition syntax.
The readable contracts and sampled runtime controls do not prove future implementation
compatibility, arbitrary compiler behavior, a shared counted-game equivalence, or P4/P5 recovery.
Those later gates require the stated mathematical observer and theorem-recovery proofs. No
legacy body delegates to a new construction on the strength of this regression baseline.
